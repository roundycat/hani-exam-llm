# 한의학 국가시험 LLM 평가 및 정확도 개선 — 최종 결과 보고서

**실험일: 2026-06-08 · 데이터: 한국보건의료인국가시험원(국시원) 공개 기출 · 평가셋: 텍스트 517문항**

> 모든 표 수치는 결과 JSON에서 결정론적으로 산출(`results/`)되었고 독립 재계산으로 교차검증되었다.
> 국시원 기출은 저작권 보호 대상이며 개인 학습·연구용으로만 사용한다.

---

## 초록

제81회 한의사·제27회 한약사 국가시험의 텍스트형 5지선다 517문항(한의사 276, 한약사 241)을 대상으로 (i) 6개 대형 언어모델의 폐쇄형(closed-book) 풀이 능력을 평가하고, (ii) 소형 오픈모델(Qwen2.5-7B)의 파인튜닝 학습 전후를 비교하였으며, (iii) 최난도 과목인 내과학의 정답률을 추론·검색 기법으로 개선하였다. 전체 벤치마크에서 GPT-5가 84.91%(439/517)로 가장 높았고 Claude Sonnet 83.75%, Claude Opus 81.24%가 뒤를 이었으며(상위 3개 95% CI 상호 중첩), 모든 모델이 한약사보다 한의사 문항에서 약 10%p 낮았다. 과목별로는 내과학2가 6모델 평균 44%로 최난도였다. Qwen2.5-7B의 466문항 LoRA 미세조정은 검증 51문항에서 51.0%→49.0%로 유의한 개선을 주지 못한 음성 결과를 보였다. 반면 **변증추론·자기일관성·다모델 앙상블**을 결합한 추론시간 확장은 내과학 전체 정답률을 74.0%→83.3%(+9.3%p)로 끌어올렸고, 여기에 **웹 한의학 레퍼런스 검색(RAG)** 을 더하자 최난도 내과학2가 56.7%→83.3%(+26.6%p)로 대폭 향상되었다. 본 보고서는 상용 모델의 강한 기저 성능, 소규모 파인튜닝의 한계(음성 결과), 그리고 추론·검색 증강의 큰 효용을 함께 정리한다.

## 1. 데이터 및 방법

**데이터셋.** 국시원 공개 기출(제81회 한의사·제27회 한약사, 2026) 587문항 중 그림 의존 70문항을 제외한 **순수 텍스트 517문항**(한의사 276, 한약사 241). 정답 100% 매칭·보기 5개 검증 완료.

**누수 방지.** 모델에는 정답을 제거한 문항만 제공, 정답(gold)은 분리 보관하여 채점에만 사용(원본 불일치 0). 파인튜닝은 시드 42로 학습 466 / 검증 51 무겹침 분할.

**채점.** 예측 보기번호(1~5)==정답. 95% 신뢰구간은 Wilson 구간. 무작위 베이스라인 20%.

**평가 대상.** ① 벤치마크: GPT-5, GPT-4o, GPT-4o-mini, Claude Opus/Sonnet/Haiku(폐쇄형, 문항당 1패스). Claude는 Claude Code 워크플로(120 에이전트), GPT는 레포 `evaluate.py`. ② 파인튜닝: Qwen2.5-7B-Instruct LoRA SFT(466문항·3에폭, Together 2×H100). ③ 개선 플로우(내과학): 변증추론 프롬프트 + 자기일관성(다회 샘플 다수결) + 다모델 앙상블 투표 + (내과학2) 웹 한의학 레퍼런스 RAG.

> 인프라: OpenAI 파인튜닝 플랫폼 종료로 GPT 파인튜닝 불가→Qwen 전환. Qwen2.5-7B는 Together 서버리스 미지원으로 2×H100 전용 엔드포인트에서 고유 서빙명으로 추론.

**표 4. 내과학 96문항 개선 (외부지식 없이, 추론시간 확장)**

| 방법 | 내과학 96 | 95% CI | 내과학2 30 | 95% CI |

| GPT-5 단일(베이스라인) | 74.0% (71/96) | 64.4–81.7% | 56.7% (17/30) | 39.2–72.6% |
| GPT-5 자기일관성 | 79.2% (76/96) | 70.0–86.1% | 66.7% (20/30) | 48.8–80.8% |

변증추론(주소증→팔강·장부변증→치법→보기비교→정답) + 모델별 다회 샘플 다수결 + GPT-5·Opus·Sonnet 앙상블 투표로 **내과학 74.0%→83.3%(+9.3%p)**. 모든 자기일관성·앙상블이 베이스라인을 일관 상회.

### 2.5 내과학2 RAG — 웹 한의학 레퍼런스 검색 주입

**표 5. 내과학2(최난도 30문항) RAG**

| 방법 | 내과학2 30 | 95% CI |
|---|---:|:---:|
| GPT-5 단일(베이스라인) | 56.7% (17/30) | 39.2–72.6% |
| no-RAG 앙상블(3모델) | 70.0% (21/30) | 52.1–83.3% |
| **RAG (웹 한의학 레퍼런스 + 변증, Opus k=3)** | **83.3% (25/30)** | 66.4–92.7% |

Opus 에이전트가 각 문항마다 보기의 처방·본초와 증상의 변증을 웹에서 조사(『傷寒論』·『金匱要略』·『東醫寶鑑』 원전 조문 등)해 근거로 주입한 뒤 변증추론. **내과학2 70.0%→83.3%(+13.3%p)**, 베이스라인 대비 **+26.6%p**.

## 3. 논의

세 갈래 실험은 일관된 그림을 그린다. **(1) 지식은 이미 가중치에 있다.** 상용 대형 모델은 폐쇄형으로도 한의학 시험에서 80%대를 기록하며, 약점은 지식형·임상추론 과목(내과학2)에 집중된다. **(2) 소규모 파인튜닝으로 지식을 새로 주입하기는 어렵다.** 466문항 SFT는 형식만 학습하고 정확도·연산량 모두 개선이 없었다(음성 결과). **(3) 정확도를 끌어올린 것은 가중치가 아니라 추론·검색이었다.** 변증추론으로 도메인 절차를 유도하고, 자기일관성·앙상블로 분산을 줄이며, RAG로 부족한 원전 지식을 외부에서 보강하자 최난도 과목이 56.7%→83.3%로 도약했다. 즉 본 과제에서 효과적 레버는 *fine-tuning*이 아니라 *test-time scaling + retrieval*이었다.

---

## 4. 한계

1. **프로토콜 차이**: 벤치마크에서 Claude·GPT-5는 내부 추론 허용, GPT-4o/mini·Qwen은 번호만 즉답 → 일부 차이는 추론 허용 여부에서 기인.
2. **표본**: 내과학2 n=30, 파인튜닝 검증 n=51로 작아 CI가 넓다. 점추정 개선은 일관되나 내과학2 수치는 **지시적**으로 해석(내과학 96의 +9.3%p가 더 견고).
3. **개선의 비용**: 자기일관성·앙상블·RAG는 단일패스 대비 연산·검색량이 수~수십 배. 정확도–비용 트레이드오프이며, RAG는 폐쇄형이 아닌 **개방형(open-book)** 설정이다.
4. **재현 주의**: 추론형(GPT-5)에 풀이 전문을 출력시키면 추론 토큰이 출력 예산을 잠식해 정답이 잘린다(1차 시도 투표 46% 빈응답 → 56%로 붕괴) → 추론은 내부 토큰에 맡기고 content엔 '정답: N'만 출력해야 정상화(79.2%).
5. **데이터·범위**: 비전 전사 기반의 드문 오탈자 가능, 단일 회차(한의사81·한약사27)만 포함.

---

## 5. 결론

상용 LLM은 한의학 국가시험을 폐쇄형으로도 80%대(GPT-5 84.9%)로 풀며, 상위 3개 모델은 사실상 동급이다. 소규모 LoRA 파인튜닝은 본 과제에서 효과가 없었으나(정직한 음성 결과), **변증추론·자기일관성·앙상블·RAG** 의 추론시간 증강은 최난도 내과학2를 56.7%→83.3%로 끌어올렸다. 향후 다회차·대규모 검증셋, 통일된 추론 프로토콜, 정제된 한의학 지식베이스 기반 RAG로의 확장이 과제로 남는다.
