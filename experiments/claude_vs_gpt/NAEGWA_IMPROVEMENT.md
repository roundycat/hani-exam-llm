# 내과학 정답률 개선 플로우 — 변증추론 + 자기일관성 + 앙상블

**실험일: 2026-06-08 · 대상: 내과학 96문항(내과학1 66 + 내과학2 30)**

내과학2는 6모델 평균 44%로 전 과목 최난도였다(단일패스 기준 최강 GPT-5도 57%).
**외부 지식(RAG) 없이**, 추론·집계 방식만으로 정답률을 끌어올리는 플로우를 적용·측정했다.

## 결과

| 방법 | 내과학 96 | 95% CI | 내과학2 30 | 95% CI |
|---|---:|:---:|---:|:---:|
| GPT-5 단일(베이스라인) | 74.0% (71/96) | 64.4–81.7% | 56.7% (17/30) | 39.2–72.6% |
| GPT-5 자기일관성 | 79.2% (76/96) | 70.0–86.1% | 66.7% (20/30) | 48.8–80.8% |
| Sonnet 자기일관성 | 75.0% (72/96) | 65.5–82.6% | 56.7% (17/30) | 39.2–72.6% |
| Opus 자기일관성 | 81.2% (78/96) | 72.3–87.8% | 66.7% (20/30) | 48.8–80.8% |
| 앙상블(전체 풀드) | 82.3% (79/96) | 73.5–88.6% | 66.7% (20/30) | 48.8–80.8% |
| **앙상블(3모델 투표)** | **83.3% (80/96)** | 74.6–89.5% | **70.0% (21/30)** | 52.1–83.3% |

**개선폭: 내과학 74.0% → 83.3% (+9.3%p) · 내과학2 56.7% → 70.0% (+13.3%p).**
모든 자기일관성·앙상블 방법이 단일패스 베이스라인을 일관되게 상회했다.

## 방법

세 가지 기법을 결합한 **추론시간 확장(test-time scaling)** 파이프라인:

1. **변증추론 프롬프트** — 각 문항을 "주소증·동반증 정리 → 팔강·장부 변증 → 치법 결정 →
   보기 처방 비교 → 정답 선택" 절차로 풀게 유도(한방내과 전문의 역할 부여).
2. **자기일관성(self-consistency)** — 모델별 다회 샘플링 후 다수결.
   Opus k=5, Sonnet k=2~5, GPT-5 k=3.
3. **앙상블** — GPT-5·Opus·Sonnet 각자의 다수결을 3모델 투표로 결합(동률 시 GPT-5).
   "전체 풀드"(모든 샘플 합산 다수결)도 비교.

- 모델 실행: Claude(Opus/Sonnet)는 Claude Code 워크플로(배치 12 × k샘플 × 8배치), GPT-5는
  OpenAI API. 모두 **폐쇄형**(웹·외부지식 없음), 정답 제거 문항만 입력.
- 채점: 예측==정답, Wilson 95% CI.

## 정직한 한계

- **추론 비용 증가**: 정확도 향상은 "더 많이 추론·샘플·투표"로 산 것이다(GPT-5 288콜 + Claude 약
  720 에이전트-문항). 단일패스 대비 연산량이 수~십수 배. 정확도-비용 트레이드오프임.
- **표본**: 내과학2는 n=30으로 작아 95% CI가 넓다(앙상블 52–83%). 점추정 개선은 일관되나
  내과학2 수치는 **지시적(indicative)** 으로 해석해야 한다. 내과학 96(+9.3%p)이 더 견고하다.
- **GPT-5 주의**: 추론형 모델에 "풀이 과정을 본문에 모두 출력"시키면 추론 토큰이 출력 예산을
  잠식해 정답이 잘린다(1차 시도에서 투표 46%가 빈응답 → 56%로 붕괴). **추론은 내부 토큰에
  맡기고 content에는 '정답: N'만** 출력시키니 정상화(79.2%)됨. (재현 시 필수)
- **RAG 미적용**: 외부 한의학 지식 주입은 하지 않았다. 추가 향상 여지로 남김.
